## À quoi ça sert
Garder vos réflexions à côté du texte, sans le salir.

## Où le trouver
Rail › Notes pour toutes les notes ; la barre flottante (bouton « Note ») pour annoter un passage sélectionné.

## Pas à pas
1. Sélectionnez un passage dans l'éditeur et cliquez sur « Note » dans la barre flottante.
2. Attachez une note existante ou écrivez-en une nouvelle.
3. Retrouvez toutes vos notes dans Rail › Notes : titre, étiquettes, texte ; filtrez la liste par étiquette.
4. Depuis une note ancrée, revenez au passage d'un clic.

## Bon à savoir
- <kbd>Ctrl</kbd>+<kbd>clic</kbd> sur un passage annoté ouvre sa note sans quitter le chapitre.
- Les notes ne sont jamais exportées avec le manuscrit. Les notes de bas de page, elles, le sont.
- Jema lit vos notes pour mieux répondre à vos questions.
- Les étiquettes classent vos notes : voir la fiche « Étiquettes des notes ».

## Si ça ne marche pas
- Le bouton « Note » n'apparaît pas : sélectionnez d'abord un passage.
- Une note ne revient pas au texte : le passage ancré a peut-être été supprimé.
