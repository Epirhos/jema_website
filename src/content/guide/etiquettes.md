## À quoi ça sert
Classer vos notes de travail pour les retrouver d'un clic : par personnage, par intrigue, par type de recherche, par chapitre à reprendre.

## Où le trouver
Barre de gauche › Notes. Dans une note ouverte, la ligne marquée d'une étiquette, sous le titre ; dans la liste, les étiquettes du projet sous la recherche.

## Pas à pas
1. Ouvrez une note et tapez une étiquette dans « Ajouter une étiquette… », puis Entrée (ou une virgule).
2. Pendant la saisie, les étiquettes déjà utilisées sont proposées : cliquez pour réutiliser la même.
3. Pour retirer une étiquette, cliquez sur sa croix (ou Retour arrière dans le champ vide).
4. Dans la liste, cliquez sur une étiquette pour n'afficher que les notes qui la portent ; cliquez de nouveau pour tout revoir.

## Bon à savoir
- Bonnes pratiques : peu d'étiquettes, mais stables. Quelques familles suffisent, par exemple un nom de personnage, une intrigue, « recherche », « à vérifier », « à reprendre ».
- Préférez une étiquette par idée plutôt qu'une phrase : « Brest 1921 » plutôt que « documentation sur le port de Brest ».
- « Élise » et « elise » sont la même étiquette : la graphie déjà utilisée dans le projet est conservée.
- Le nombre à côté de chaque étiquette indique combien de notes la portent.
- Les étiquettes restent dans vos notes : elles ne partent jamais à l'export.

## Si ça ne marche pas
- Une étiquette n'apparaît pas dans la liste : elle n'est portée par aucune note pour l'instant.
- La liste semble vide : un filtre d'étiquette ou une recherche est actif. Cliquez sur l'étiquette mise en valeur ou effacez la recherche.
