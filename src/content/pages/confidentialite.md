Cette page concerne le site de présentation de Jema. L'application installée sur votre ordinateur a sa propre politique, livrée avec le logiciel : vos manuscrits ne quittent jamais votre machine.

## En bref

- Ce site ne dépose aucun cookie, ni publicitaire ni de mesure d'audience.
- Il mesure sa fréquentation de façon anonyme, sans cookie.
- Il ne vous demande aucun compte.
- Les polices de caractères sont hébergées sur le site lui-même : aucune requête vers Google.

## Connexions techniques

Comme tout site web, l'hébergeur (GitHub, Inc., États-Unis) reçoit votre adresse IP et les informations techniques habituelles d'une requête, pour afficher les pages. Pour vous proposer la dernière version de Jema, votre navigateur interroge aussi l'API de GitHub. Ces données sont traitées par GitHub selon sa propre politique de confidentialité.

## Mesure d'audience

Pour savoir combien de personnes visitent le site, d'où elles viennent et ce qui les intéresse, nous utilisons **Umami**, un outil de mesure d'audience **sans cookie**. Il enregistre des informations agrégées : pages vues, site d'où vous arrivez, pays, type d'appareil, temps passé, et les boutons utilisés (par exemple « Télécharger »). Il ne conserve ni votre adresse IP, ni aucun identifiant qui permettrait de vous reconnaître d'une visite à l'autre. Si votre navigateur envoie le signal « Ne pas suivre » (Do Not Track), aucune mesure n'est faite.

## Stockage local

Pour éviter d'interroger GitHub à chaque page, le numéro de la dernière version de Jema est gardé dans votre navigateur le temps de la visite (stockage de session). Il n'est jamais transmis et s'efface à la fermeture de l'onglet.

## Nous écrire

Si vous nous écrivez par courriel, nous utilisons votre adresse et votre message uniquement pour vous répondre et améliorer Jema.

## Vos droits

Vous disposez d'un droit d'accès, de rectification, d'effacement, de limitation, d'opposition et de portabilité sur les données vous concernant. Pour les exercer : [editor.jema@gmail.com](mailto:editor.jema@gmail.com). Vous pouvez aussi adresser une réclamation à la [CNIL](https://www.cnil.fr).
